# Lab 04 – Implement Virtual Networking (AZ-104)

Notes and documentation for Lab 04 of AZ-104.

## Overview

In this lab, I worked with **Azure Virtual Networking** to design and implement virtual networks and subnets, configure Network Security Groups (NSG) and Application Security Groups (ASG), and set up both public and private Azure DNS zones.

The objective was to understand how to build a scalable network architecture in Azure, secure network traffic, and implement name resolution for both public and private environments.

## Business Scenario

The organization is planning a large-scale network infrastructure to support current workloads and future growth.
Core services require a large and well-structured virtual network, while manufacturing systems need their own isolated network prepared for a high number of connected devices.

Additionally, the organization needs to:

* Control traffic flow using security rules.
* Allow secure communication between application tiers.
* Provide both public and private DNS name resolution for their services.

## What I Learned

* How to design and create Azure Virtual Networks and subnets
* How to deploy virtual networks using ARM templates
* How to configure and use Network Security Groups (NSG) and Application Security Groups (ASG)
* How to control inbound and outbound traffic using security rules
* How to create and configure public and private Azure DNS zones
* How to link private DNS zones to virtual networks and manage DNS records
